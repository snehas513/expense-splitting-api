# Expense Splitting API

A backend application for managing shared expenses, tracking balances,
and settling payments between members of a group.

## Project Overview

Expense Splitting API allows users to:
- Create groups and add members.
- Record shared expenses.
- Split expenses equally or unequally.
- Track who owes whom.
- Record settlements between members.

## Technology Stack

- Ruby on Rails (API mode)
- MySQL
- Docker
- REST APIs

## Project Structure

- `backend/` - Rails API application
- `frontend/` - Streamlit frontend (planned)
- `docs/` - Project documentation
